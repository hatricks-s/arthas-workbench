# Community code of conduct

We want a respectful, useful space for people improving Java diagnostic tools.

## Expected behavior

- Discuss ideas and code with patience and concrete evidence.
- Welcome different experience levels, languages and backgrounds.
- Give actionable feedback and accept corrections.
- Respect privacy, ownership and authorization boundaries.

## Unacceptable behavior

Harassment, discriminatory language, personal attacks, threats, publishing private information without consent, and deliberate disruption are not acceptable. Do not post credentials or private company information when discussing a problem.

## Scope and enforcement

This policy applies to repository issues, pull requests, discussions and other spaces maintained for this project. Maintainers may edit or remove harmful content, request changes, or restrict participation based on severity and repetition. Enforcement should be proportionate and explained where practical.

Use GitHub's **Report content** mechanism for private conduct reports or block/report abusive accounts through GitHub. Do not publish another person's private information in order to make a report. Security reports follow [SECURITY.md](SECURITY.md).
