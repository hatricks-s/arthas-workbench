02 · 免运维三级自适应注入

12MB 精简包秒级下发 + 全量 jattach

剔除无用包，仅保留 agent/core/spy.jar + 双架构静态 jattach。不启动第二个 JVM，濒临 OOM 容器也能安全挂载：

  1. Tier A（内网 HTTP Pull · ~0.3s）：Pod 内自带 curl 从工作台签名内网 URL 拉取并校验 SHA-256，/tmp 命中缓存直接跳过。
  2. Tier B（WS Stdin 流式解包 · ~3s）：禁外连容器直接走 exec tar -xzf - 流式直灌，32KB 分帧流控告别 staticperl。
  3. Tier C（微接收器 / 临时容器兜底）：极简无 tar 镜像注入 80KB 静态接收器或 K8s Ephemeral Container。
